# Repository visibility for TVT submission

IEEE Vehicular Technology Society's current author instructions state that IEEE Transactions on Vehicular Technology uses **single-anonymous peer review**: reviewers' identities are hidden from authors, while reviewers can see the authors' identities. An anonymized repository is therefore not required by TVT's stated review model. If the authors and rights holders approve public release, a normally named public GitHub repository is appropriate.

If the submission portal gives manuscript-specific instructions for repository links, follow those instructions. This release contains no full manuscript PDF or author email addresses. Add the public repository URL to the manuscript's code/data availability statement only after the repository is created and the content is final.
